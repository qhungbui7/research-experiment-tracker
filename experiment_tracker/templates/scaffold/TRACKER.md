# Issue Tracker

Single source of truth for all experimental findings, bug discoveries, and methodological audits across all rounds.

## How to read this

- Issues are numbered globally: `I-001`, `I-002`, ...
- Status: `open` | `fixed` | `wontfix` | `disputed`
- Severity:
  - **P0**: Critical correctness bug, invalid metric computation, data leakage, or fatal run crash.
  - **P1**: Paper/claim mismatch, flawed comparison, or significant baseline confound.
  - **P2**: Experimental quality defect, under-powered seeds, or missing control comparison.
  - **P3**: Minor discrepancy, plotting label inaccuracy, or incomplete secondary ablation.
  - **P4**: Documentation cleanup, styling inconsistency, or code refactor.
- `Found`: The round where first discovered (e.g. `experiment_001/round_001`).
- `Resolved`: The round, commit, or action that closed the issue.
